# The Two Books (Qur'an ↔ Image Processing) — Course Index

A **17-lecture, 3-hour-per-session** university course reading the Book of Scripture (the Qur'an, *tadwīn*) beside the Book of Creation (nature's data, *takwīn*) as two works of **one Author**, compared **as structure** — never as identity. Its object is the **sūra as a 2-D image**: a chapter becomes a matrix (āyah × feature), read with the mathematics of **image processing**. Every parallel is audited **✓ Supported / ✗ Breaks / ~ Silent**, and every inferential claim is validated against a **Monte-Carlo null and a natural-language baseline**.

> Parallel to, and built to the same locked standard as, the **signal** course (`../signal/`, the āyah as a 1-D signal) and the **biology** course (`../biology/`). Same anchor, same discipline, **no drift**.

**Anchor (locked):** vectorize on the **ROOT (ریشه, col 4)** — highest semantic power (biology root↔codon; NLP stem/lemma); surface forms (col 5) and morphology (col 7) are complementary channels. The 2-D object is built from roots (e.g. an āyah×root matrix, a root co-occurrence matrix, a sūra×sūra similarity matrix).

> **Meta-thesis carried from the signal course (evidence-based).** The Qur'an's detectable latent structure is **relational/organizational, not in local content statistics** — validated by the muqaṭṭaʿāt-as-positional-pointers result (label-permutation p = 2×10⁻⁵, all 29 sūras). **Relations are matrices**, so the 2-D image is the natural object where this structure is expressed (e.g. the Ḥawāmīm form a brighter similarity block: within 0.68 vs 0.47 to the rest). This course is where the relational frontier is worked.
